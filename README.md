# Engenharia de Dados — Estudos e Prática

Bem-vindo(a) ao meu repositório de estudos em Engenharia de Dados.  
Aqui concentro exercícios, anotações, desafios e projetos desenvolvidos ao longo da minha formação prática na área de dados, utilizando conteúdos da formação de Engenharia de Dados da Alura e estudos complementares.

O objetivo deste repositório é acompanhar minha evolução técnica, consolidar conhecimento e construir um portfólio voltado para dados, analytics e engenharia de dados.
